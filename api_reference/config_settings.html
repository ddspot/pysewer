Configuration Setting#

Important

Apply custom configuration before creating the ModelDomain:

pysewer.set_custom_config(custom_path="my_settings.yaml")  # 1st
md = pysewer.ModelDomain(dem, roads, buildings)            # 2nd

The preprocessing parameters clustering and connect_buildings are consumed while the connection graph is built inside ModelDomain(...); config overrides applied afterwards cannot affect them. Most other parameters (including pump_penalty and the optimization values) are read from the live config at the pipeline stage that uses them.
